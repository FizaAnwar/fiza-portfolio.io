# Fiza Anwar Portfolio

Original React/Vite portfolio customized from the information in Fiza Anwar's resume.

## Run locally

```bash
npm install
npm run dev
```

Open the local Vite URL shown in the terminal.

## Production build

```bash
npm run build
npm run preview
```

## Before publishing

1. Replace the LinkedIn URL in `src/main.jsx` with the exact profile URL.
2. Replace project "Discuss project" behavior with real repository/demo links if desired.
3. If you want a real profile photo, replace the `FA` avatar in `src/main.jsx` with an image in `public/`.
4. The supplied resume is already included as `public/Fiza_Anwar_Resume.pdf`.

## GitHub Pages

For GitHub Pages, install the `gh-pages` package or use a GitHub Actions workflow. If your repository is `FizaAnwar.github.io`, the Vite base can remain `/`.
